## 同一事务的操作负担

同一份地方路线第3回合实际 UI 存档，先通过真实财政上缴2制造电网下期维护缺口并临时占用计划主任；恢复此档分别测量。记录从无打开面板到查看同一维护接管受阻预览，包含“预览后果”，排除保存/验算操作。两次均取消，不扣资源。

| 入口 | 实际 DOM 点击 | 不同详情面板 | 路径 |
| --- | --- | --- | --- |
| 原地图菜单 | 5 | 3 | 经济建设 → 国家财政 → 展开接管 → 中央承担 → 预览后果 |
| 治理桌面 | 3 | 2 | 电网卡 → 中央承接 → 预览后果 |

这是单一典型查询的可复现实测，点击减少40%，面板减少1个；不代表全部事务平均，也没有测量真人思考时间、寻找时间或认知负担。继续点击受阻原因→计划职位→任命温序→重新接管后，下期预计欠付从1到0，产权仍是南岭，并出现维护议程。见 [Linux浏览器原始记录](BROWSER_RESULTS_LINUX.json) 与 Case A～D 截图。
