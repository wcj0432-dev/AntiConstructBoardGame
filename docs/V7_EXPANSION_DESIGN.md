# 五省扩图的准备与启用门槛（尚不可玩）

`src/v2/expansion.ts`把东海、西陲定义为独立的PlannedProvinceId，`playable:false`。它们未加入ProvinceId、国家财政、存档、地图或目标；不会伪装成两块新颜色和免费资源。

东海魔法都市：群众/工业/港湾，依赖南岭能源、工业省物流；新政治问题是都市税源、公开救援与安全保密权限，机构为都市救援联社和魔法少女代表会议。

西陲江湖自治：江湖/农业/灵脉，依赖北境物流、南岭教育；问题是私人承诺与国家标准、地方司法的互认，机构为承诺公所与门派议事会。

启用顺序：

1. 抽出活动省注册表，由它生成账户、政府职位、权利/信任、调查与区域连线。替换现存三省数组前运行全部财政/维护/师承/目标迁移检查。
2. 先开放东海单省实验场景，明确初始税源、维护义务、贸易与能源断供后果；实际地方特色行动不得借中央资金凭空结算。
3. 给原八路线声明全国覆盖还是核心省覆盖；终局、通讯、法典、三省老档迁移必须同用该规则，不随意把旧胜利变不可能。
4. 做一条旧省供能→东海产业→实际回拨/上缴→全国工程链及一条断供反例，再开放西陲。
5. 为五省版本建立正常资源12回合路线与四桌面/原生缩放验收，最后再进入正式菜单。

本轮只交付数据设计与未开放断言；五省最小可玩验证留待后续。
